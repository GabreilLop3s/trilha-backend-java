## 🎯 Objetivo
Repositório central para documentar minha jornada de 12 meses de especialização em Engenharia de Software Backend. O foco desta trilha é dominar o ecossistema **Java e Spring Boot**, otimização de banco de dados e infraestrutura Cloud/Docker, construindo a ponte técnica entre a manutenção de sistemas legados complexos e arquiteturas modernas de alta disponibilidade.

Este projeto pavimenta a base técnica para a minha futura transição para **Cloud Security e Cibersegurança Ofensiva**.

## ⏱️ Prazo e Cadência
- **Duração Estimada:** 12 meses (Novembro/2026 a Novembro/2027)
- **Cadência de Estudo:** 8 a 10 horas semanais (focadas de quinta a domingo)
- **Metodologia:** Prática guiada e construção de projetos reais, com controle de evidências semanais.
